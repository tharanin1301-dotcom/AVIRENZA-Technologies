## Columns

| Column | Type | Description |
|--------|------|-------------|
| `Country name` | string | Country name |
| `Regional indicator` | string | Geographic region (10 regions) |
| `Ladder score` | float | Happiness score (Cantril ladder, 0–10 scale) |
| `Logged GDP per capita` | float | Log of GDP per capita (natural log) |
| `Social support` | float | National average of binary response (0/1) |
| `Healthy life expectancy` | float | Healthy life expectancy at birth (years) |
| `Freedom to make life choices` | float | National average satisfaction with freedom |
| `Generosity` | float | Residual of regressing national donation rates |
| `Perceptions of corruption` | float | Average of corruption perception measures |

## Source Details

The **World Happiness Report** is an annual landmark survey of the state of global happiness.
Data is collected by the **Gallup World Poll** — a nationally representative survey of approximately 1,000 respondents per country.

The **Ladder score** (Cantril ladder) is the primary happiness metric: respondents imagine a ladder
where 10 is their best possible life and 0 is the worst, and indicate where they currently stand.
